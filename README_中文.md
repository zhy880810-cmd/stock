# 投资助手 · 云端版（GitHub Pages + 每日自动更新）

**这是什么：** 一个放在网上的投资小网页。每个工作日北京时间早上约 8:50（对应 UTC 00:50，周二到周六），GitHub 的服务器会自动帮你：
拉取自选股收盘价 → 让 AI 联网写一份中文「每日雷达」（隔夜美股、美联储/宏观、自选相关消息、3～5 只异动股）→ 更新网页。
你的电脑关机也照样更新，手机和电脑打开同一个网址就能看。

> ⚠️ **先看隐私提醒**
> - 网页有一层**访问密码**：第一次打开时设置（输入两次），这台设备会记住，不用每次再输入。可在「设置」里改密码，或点「锁定本页」后重新输入。
> - **这只挡住随手打开网页的普通人，不是真正的加密。** 公开仓库和 `data.json` 里仍然有自选代码、价格和新闻雷达，懂技术的人即使不输入密码也能看到这些。**不放**你的持仓数量、成本、金额，也没有 API 密钥。
> - 密码只以哈希形式存在**这台设备的浏览器**里，不会写入仓库、`config.json` 或 `data.json`。
> - GitHub Pages **是公开网页**，知道网址的人都能打开。免费账号若用 GitHub Pages，仓库也必须是**公开**的。
> - 你的持仓只存在**你自己浏览器**里（localStorage）。网页会在你本机把云端价格和你的持仓合起来算盈亏、算止损预警。
> - 代价：电脑和手机的持仓要**各录一遍**（或用「设置 → 导出/导入」同步）。换浏览器、清缓存会丢，记得导出备份。
> - API 密钥只放 GitHub 的 Secrets，**千万不要**写进文件、也不要发给别人。
> - 以后如果想减少 `data.json` 在 GitHub 上被搜到的机会，可以把仓库改成 **Private**。用 Cloudflare Pages 部署时支持私有仓库，不必为此去绑卡开通 Zero Trust。注意：已经发布的网页和上面的 `data.json` 仍然可以直接打开，密码锁挡不住会看网址的人。
>
> 内容仅供学习与记录参考，**不构成投资建议**。AI 联网整理的内容可能有错，「异动股」只是线索，不是买入理由。

## 一、一次性设置（大约 15 分钟，全程网页操作，电脑上做最方便）

### 第 1 步：注册 GitHub
1. 打开 <https://github.com>，点 Sign up，用邮箱注册，按提示验证邮箱。
2. 记住你的**用户名**（后面网址里要用）。国内打开如果很慢，可能需要开 VPN。

### 第 2 步：新建仓库
1. 登录后点右上角 **＋ → New repository**。
2. Repository name 随便起，比如 `invest`。
3. 选 **Public**（公开）。
4. 勾选 **Add a README file**（这样仓库不是空的，后面更好操作）。
5. 点绿色的 **Create repository**。

### 第 3 步：上传文件
1. 把我发你的压缩包 `invest-cloud.zip` **先解压**到桌面（GitHub 不能直接传 zip）。
2. 在你的仓库页面点 **Add file → Upload files**。
3. 打开解压后的文件夹，**全选里面的所有东西**（`index.html`、`config.json`、`data.json`、`requirements.txt`、`README_中文.md`、`scripts` 文件夹、`.github` 文件夹），拖到网页的上传区域。
4. 等文件都显示出来，拉到最下面点绿色的 **Commit changes**。

> 如果拖完以后发现没有 `.github` 文件夹（有些浏览器会漏掉以点开头的文件夹），就用这个办法补上：
> 仓库页面点 **Add file → Create new file**，在文件名那一栏**直接输入** `.github/workflows/daily.yml`（输入斜杠会自动变成文件夹），
> 然后把解压文件夹里 `.github/workflows/daily.yml` 的全部内容复制粘贴进去，点 **Commit changes**。

### 第 4 步：填 API 密钥（Secrets）
1. 仓库页面点上方的 **Settings**（设置）。
2. 左边找到 **Secrets and variables → Actions**。
3. 点 **New repository secret**：
   - Name 填 `GEMINI_API_KEY`
   - Secret 粘贴你的 Gemini 密钥（获取方法见下面第三节）
   - 点 **Add secret**。

### 第 5 步：允许自动更新写回仓库
1. Settings 左边 **Actions → General**。
2. 拉到最下面 **Workflow permissions**，选 **Read and write permissions**，点 **Save**。

### 第 6 步：开启网页（Pages）
1. Settings 左边点 **Pages**。
2. **Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main`，文件夹选 `/ (root)`，点 **Save**。
4. 等 1～2 分钟，刷新这个页面，上面会出现你的网址，格式是：
   `https://你的用户名.github.io/仓库名/`

### 第 7 步：手动跑一次，看看有没有成功
1. 仓库上方点 **Actions**。（如果提示 “I understand my workflows, go ahead and enable them”，点它。）
2. 左边点 **每日雷达**，右边点 **Run workflow → Run workflow**。
3. 等 1～3 分钟，出现绿色 ✅ 就成功了。红色 ❌ 就点进去看报错（常见原因见最后的“出问题怎么办”）。
4. 回到你的网址，刷新页面，「雷达」页应该就有内容了。

### 第 8 步：加书签
- **电脑：** 浏览器里按 Ctrl+D 收藏网址。
- **手机：** 用浏览器打开网址 → 菜单里选“添加到主屏幕”，以后像 App 一样点开。
- 第一次打开后，先设置访问密码（连续输入两次）。之后同一台设备会记住。再到「持仓」页录入你的持仓，到「设置 → 止损预警」设阈值。

### 已经部署过？这次只更新网页说明（2026-11-16 空仓/持仓显示）
这次按投资助手最新意见，把空仓和持仓的展示分开，并把未确认技术价折起来。请只覆盖：
- `index.html`
- `README_中文.md`

**不要改** `.github/workflows/daily.yml`，也不必覆盖 `scripts/update_daily.py`（每日计算口径未改）。定时仍是周二到周六 UTC 00:50（北京时间约 08:50，`50 0 * * 2-6`）。
**不要上传** `data.json`、`config.json`，也不要把密钥、持仓数量、成本或盈亏写进任何文件。不必为了这次改动去 Actions 里手动跑「每日雷达」。

1. 网页更新后等 1～2 分钟，打开网址并**强制刷新**（电脑可用 Ctrl+F5，Mac 可用 Cmd+Shift+R；手机浏览器用“刷新”或清一下该网站缓存）。空仓卡片会只显示已确认买点和距官方收盘的剩余距离；有成交记录后才会出现有效止盈止损。
2. 现有 `data.json` 不用改。已确认的固定价仍在云端计划里，不会因为空仓隐藏而被删掉。

## 二、日常使用
- 第一次打开会先设置访问密码；同一台设备以后会记住。这只挡住随手打开的人，公开的自选代码、价格和新闻雷达仍在仓库和 `data.json` 里。
- 每个工作日早上打开网址，先看「雷达」页：按买点距离排序的价格表（含分批梯子、盘后价和「新触及」）、杠杆 ETF 只持有一只的规则、QQQM/SCHD 定投行情、标普 500 涨跌各前 3 名、1～3 条大新闻（没有则隐藏），以及按历史价格和波动在本地算出的**技术参考**止损、止盈和补充批次（不是 AI 判断，可在本机覆盖）。有持仓或已设 1500 美元总资金时，还会显示分账户盈亏、相对起点的收益率、资金曲线和定投进度。
- 「雷达」页的按钮「＋ 把云端自选加入我的自选」可以把云端清单一键加到本机自选。
- 想改雷达里的买点或规则：到「AI」页直接说，确认「应用到雷达」后立即生效；也可在「设置」里「编辑策略」。只存在本机浏览器，不用再上传 GitHub。
- 原来的功能都还在：自选、持仓盈亏、财经日历、多家 AI 对话（要在「设置」里填各家密钥，只存在你本机浏览器）。
- AI 对话框新增「插入图片」按钮，也可以把截图直接粘贴（Ctrl+V / 手机长按粘贴）或拖到输入框里，每次最多 4 张（jpg/png/webp/gif），会在本机压缩后发给你选的 AI 做识别。只发图片不打字也可以，页面会自动带上一句请 AI 识图并提炼行情/财报要点的提示。这些图片只存在你这个浏览器的对话记录里，不会上传到 GitHub，也不会写入 data.json；如果本地存储空间不够，会保留文字并缩小或去掉部分历史图片。注意：网页是静态 GitHub Pages，浏览器直连 Gemini 等接口经常会因跨域（CORS）或网络失败，这不影响云端每天自动更新的雷达。网页里即时聊天若连不上，可改用 DeepSeek（国内通常可直连），或换一家能连上的接口；部分模型（如 DeepSeek 的 deepseek-v4-pro）不支持识图，需要改成 deepseek-flash。
- 云端数据没更新、或者网址打不开时，页面会给出提示；自选/持仓/日历/AI 对话照常能用。
- 只有周二到周六早上约 8:50（北京时间）会自动更新（对应美股周一到周五的收盘）。GitHub 定时任务经常会晚几分钟到几十分钟。美股休市日，价格会和前一天一样。

## 三、怎么拿 AI 密钥
### Gemini（默认，推荐先用这个）
1. 打开 <https://aistudio.google.com/apikey>，用 Google 账号登录。
2. 点 **Create API key**，复制出来的那串字符，粘贴到上面第 4 步的 Secret 里。
3. **在中国大陆打开 Google AI Studio 可能需要开 VPN。** 但每天的自动任务是在 GitHub 国外的服务器上跑的，不受你网络影响，所以只有“申请密钥”那一步需要。
4. 免费额度和“联网搜索”是否免费，以 [Gemini 价格页](https://aistudio.google.com/docs/pricing) 为准，用之前请先确认。

### 改用 Grok（可选）
1. 去 <https://console.x.ai> 创建 API 密钥，并在 Billing 里充一点钱（Grok 没有免费额度）。
2. 在 GitHub 的 Secrets 里再添加两个：
   - `XAI_API_KEY` = 你的 xAI 密钥
   - `AI_PROVIDER` = `grok`
3. 想换回 Gemini：把 `AI_PROVIDER` 改成 `gemini`，或者直接删掉它。
4. 模型默认 `gemini-3.8-flash` / `grok-4.7`（与网页里 Grok 对话默认一致）。想换模型，加一个 Secret：`GEMINI_MODEL` 或 `XAI_MODEL`，填模型名。密钥里的 `XAI_MODEL` 会覆盖默认值。模型名会更新，如果报“模型不存在”，就去各家官网看现在的名字。

## 四、怎么改自选股
1. 仓库里点开 `config.json`，点右上角的铅笔图标（Edit）。
2. 改 `"watchlist"` 那一行，比如 `["SPYM", "QQQM", "TQQQ", "SOXL", "NVDA"]`，代码用英文大写，美股/ETF 直接写代码。
3. 想显示中文名，改 `"names"` 里对应的名字（可选）。
4. 点 **Commit changes**。下次自动更新，或者手动 Run workflow 一次就生效。
5. 港股写成 `0700.HK`，加密货币写成 `BTC-USD`（这两种我只做了基本支持，美股最稳）。
6. **config.json 是公开的**，只写代码，别写数量和金额。

## 五、可选：微信推送（Server酱）
1. 打开 <https://sct.ftqq.com>，用微信登录，拿到 SendKey。
2. 在 Secrets 里添加 `SERVERCHAN_KEY` = 你的 SendKey。
3. 每天更新完会推一条简短中文摘要：新触及的买点、自动换股、标普 500 涨跌前 3、大新闻标题，以及网页链接（默认 <https://stock-6d3.pages.dev>，可在仓库 Variables 里设 `PAGES_URL` 改），**不含任何金额和持仓**。不填 `SERVERCHAN_KEY` 就不推送；推送失败只记一行日志，不影响更新。

## 五·一、把持仓发进微信推送（可选）
持仓默认只存在你的浏览器里，云端脚本看不到，所以「持有仓」不会自动出现在微信里。若你希望推送也带上持有仓和买卖点：

1. 打开网页「设置」，点「复制持仓给推送用」（会复制当前持仓数量、成本、账户、你填的止盈止损、总资金和现金，不含 API 密钥）。
2. 到 GitHub 仓库 **Settings → Secrets and variables → Actions**，新建密钥，Name 填 `HOLDINGS_JSON`，把刚才复制的 JSON 整段粘贴进去保存。
3. 每次买卖之后，再点一次「复制持仓给推送用」，把密钥更新成最新内容。不更新的话，推送仍是旧持仓。
4. 不设这个密钥也没关系：推送里会跳过「持有仓」，观察仓、定投、涨跌榜和大新闻照常发送。

脚本**只在生成推送时**读取这个密钥，**绝不会**写入 `data.json`、日志或任何提交到仓库的文件。

## 五·二、自动换股
- 模型如果提到别的机会，脚本只把它记成待复核，**不会**改候选买点，也**不会**用 ATR 生成新的可执行买档。要改买点，仍须你在网页上确认。
- 当前计划写在 `data.json` 的 `plan.active`（只有代码、买点、名称，不含任何持仓）；`config.json` 只是第一次的种子。换股记录在 `plan.swap_log`，网页上有「自动换股记录」。
- 防抖：14 天内最多换 3 次；刚换进来的 5 天内不再被换；刚换出的 14 天内不换回。三只杠杆 ETF 只拿一只的规则不变。
- 你已在网页里标记买入/持仓的标的，即使被换出计划，也会继续显示并保留止盈止损提醒（这个只存在你自己的浏览器里）。

## 五·三、在网页里改雷达策略（不用再上传 GitHub）
公开网页不能安全地从浏览器改写 `data.json`（那需要把写权限密钥放到公开页面里）。所以改法是：

- 云端任务照常每天写入价格、涨跌榜、大新闻、技术参考和自动换股记录。
- 你的策略（计划标的、买点梯子、杠杆只拿一只、NVDA 只看不买、BRK 决定日、定投标的、自动换股偏好、满仓行为、止盈止损覆盖）保存在这台设备浏览器的 localStorage 里，**不会从网页写回 data.json**。
- 雷达页会用本机策略覆盖云端 `plan.active` 来显示买点和规则；价格仍用云端行情。若你新加的代码在 data.json 里还没有价格，卡片会提示：可点顶部「刷新行情」试取公开报价，或等下次每日任务跑完后再看缺口。

使用方式：
1. 打开「AI」页（任意已填密钥的接口），直接说例如「把 ADBE 买点改成 200、180」「加入 AMD，买点 140/130」。
2. AI 会在回复里附带一段 `strategy-json`（页面会藏起原始代码块），下方出现预览和按钮。核对后点「应用到雷达」，才会写入本机并立即重绘雷达页；点「取消」则不改。
3. 也可以在「设置」或雷达页点「编辑策略」，手动改列表和规则，或导出/导入 JSON、恢复为云端默认。
4. 本机策略生效时，雷达上会有「本机策略覆盖中」和上次保存时间（北京时间）。电脑和手机是各自独立的，可用「设置 → 导出/导入」或策略 JSON 同步。

## 六、要花多少钱
- 为省钱，云端脚本每天**只调用一次** AI（Grok 或 Gemini），只查「标普 500 涨跌各前 3 名的原因」和「1～3 条重大新闻」（外加至多一条明显更好的机会）；价格、买点缺口、止盈止损、补充批次都在本地用 yfinance 数据计算，不再逐只查新闻。
- GitHub：免费。
- Gemini：免费额度通常够这种“每天一次”的用量，大概率 0 元，但额度政策会变，以官网为准。
- Grok：没有免费额度，每次运行要花一点点钱（模型调用 + 联网搜索，具体见 [xAI 价格页](https://docs.x.ai/developers/pricing)）。每天一次的话，预计一年几十元量级，实际以官网价格为准。

## 七、已知限制
- **定时会晚：** GitHub 的定时任务经常晚几分钟到几十分钟才开始跑，高峰期更久。
- **行情接口不是官方的：** 价格来自 yfinance（抓取雅虎财经），偶尔会失败。失败时页面会保留上一次的价格并标“过期”。
- **AI 可能出错或失败：** 失败时只更新价格，页面会写明原因，并显示上一次的雷达内容（标“旧内容”）。
- **github.io 在国内有时打不开或很慢**，手机不开 VPN 可能看不到。
- **仓库长期没动静时 GitHub 可能暂停定时任务**（一般每天有更新提交就不会）。如果页面提示“很多天没更新”，去 Actions 页面看看，必要时点一下启用。
- **提醒只在你打开网页时计算**，不会主动推送到手机（想要推送请用上面的 Server酱）。
- **持仓不跨设备同步**（这是为了隐私）。

## 八、出问题怎么办
| 现象 | 怎么办 |
|---|---|
| Actions 红色 ❌，提示 `Permission ... denied` 或 push 失败 | 回第 5 步，把 Workflow permissions 改成 Read and write |
| 页面显示“示例占位数据” | 还没成功跑过。去 Actions 手动 Run workflow |
| 页面说“AI 雷达没有生成成功：没有设置 GEMINI_API_KEY” | 检查 Secrets 名字是不是一字不差：`GEMINI_API_KEY` |
| 提示 API key not valid | 密钥复制错了，重新生成一个，更新 Secret |
| 提示模型不存在 | 用 `GEMINI_MODEL` / `XAI_MODEL` 这个 Secret 指定一个现在有效的模型名 |
| 网址打开是 404 | Pages 还没生效，等几分钟；或检查第 6 步的设置 |
| 价格全是空的 | 多半是雅虎接口临时故障，过一会儿再手动跑一次 |

## 止损 / 止盈怎么取值、距离怎么算（2026-11-16 空仓/持仓再修正）

- **空仓与持仓分开显示**：还没有录入实际成交（数量、成交价、成交日、手续费及是否含费）时，卡片只显示**已确认买点**，以及相对**最新官方常规收盘**还差多少。止盈止损整段不展示、不算距现价距离，也不会把技术价自动填成执行价。已确认的固定价仍保存在计划里（TQQQ 止损 45、止盈 60/68、买点 52/50；SOXL 止损 38、止盈 60/75、买点 47/41；KORU 止损 6、止盈 8.5/10.5、买点 7/6.5），只是空仓时不拿出来当有效规则；录入成交后自动作为有效规则。
- **有持仓后**：才显示已确认的有效止盈止损、本机持仓盈亏，以及相对**含费成本**的距离。触及提醒仍只看官方常规收盘，触到就是整笔复核，不自动下单。任一档止盈都是整笔卖出复核，不会自动滚到下一档。可继续用「已复核，继续持有」。
- **NVDA、ADBE 没有已确认止盈止损**：页面写「止盈止损待实际买入方案确认」，不会把 ATR/技术价包装成一套可直接采用的执行价。NVDA 在 2026-11-18 财报前只看不买；即使出现参考买点，也不会变成可执行买点。
- **技术参考要折叠**：未确认的技术止盈止损放在折叠的「技术参考（未确认，非执行规则）」里，不当成主推荐。空仓或只看不买时不能点「采用」。普通股票的技术参考若未经复权/ATR 核验，只作建议，按钮禁用。杠杆 ETF 仍须公司行为校验通过后，且已有持仓、参考与已确认价不同，才能进入核对。
- **已确认买点与参考买点/补仓建议分开**：参考不会自动覆盖已确认价。「采用」只打开核对（旧价、新价、影响），再确认才写入，取消则不变，本机保留修改记录。参考须标明依据（对照收盘、估值假设、数据日）；依据不足或复权/ATR 未核实则只显示建议、禁用采用。新的加仓/买点档若 ≤ 已确认有效止损，视为冲突，不能加入梯子。「改我的价」仍可用，同样要核对，未设定时输入框留空。页面不会凭空生成新的买点或补仓数字。
- **执行价只来自已确认的价**：你在网页「改我的价」、持仓里填的，或核对后采用的（标「我的」）＞ 你已确认的固定价位（标「已定」，写在 `config.json` 的 `agreed_sltp`，止盈最多两档）。技术参考只出现在折叠参考区，确认采用之前不是执行价，也不参与提醒。
- **三只杠杆 ETF（TQQQ、SOXL、KORU）** 的技术参考要等公司行为校验。没校验显示「未校验」，失败显示「校验失败」，都写明原因；覆盖日没有证明到最新时，不能当成没有新的拆股。
- 止损止盈只在已确认的常规收盘之后提醒。盘中或盘外刷新不会触发。系统只提醒，不提供止损保护。
- 「标记已买入」要填成交数量、成交价、成交日和手续费。到价或未成交不算持仓。页面不再生成「补 xx」加仓价。
- **采用要两步**：先进入核对，再点一次确认。取消不改。修改记录只留在本机，可随配置快照导入导出。
- **补充价 ≤ 有效止损**（含相等）是策略冲突，只标出来，不能加入梯子，也不悄悄改价。TQQQ 的 45.11 高于已定止损 45，不是这种冲突。
- 到价是「待复核」，不是买入指令。三只杠杆 ETF 最多同时持有一只；已经多持的会警告，不会自动删。两档止盈都是复核价，卖出按整笔一次，不会自动分批。
- **百分比分母**：距已确认买点用**官方常规收盘**；持仓盈亏和到止盈止损的距离用**含费成本**；触及提醒仍看官方常规收盘。不用盘前/盘后价，也不在空仓卡片上重复写「分母：常规时段现价」。
- **技术参考公式**：止损 = 取「基准最低价 − 1.5×ATR」和「近三月/20 日低点 − 0.5×ATR」中更低的；止盈 = 基准均价 + 3×ATR（或近三月高点，限在 2~6×ATR 内），且不低于基准最高价的 103%。
- **价格显示两行**：主行「收盘」=常规时段收盘价和相对上一交易日收盘的涨跌（盘中运行时标「盘中」）；第二行灰字「参考」=当前盘前或盘后价，涨跌相对今日收盘。买点缺口和止盈止损触及只用官方常规收盘，不用盘外价。没有盘外价就不显示第二行。夜盘（美东约 20:00–04:00）目前没有数据源，不显示。
- **数据防呆**：遇到拆股/并股式跳变，有拆股记录就按比例还原，否则只用跳变之后的数据；ATR 占现价过大（普通品种 >12%，杠杆 ETF >20%）会忽略并用估算波动，页面会标「数据提示」。
- `config.json` 里 `agreed_sltp` 只写价位，不写数量、成本、盈亏。想取消某只的固定价，把它写成 `{}`。
